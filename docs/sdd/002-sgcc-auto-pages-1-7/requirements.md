# 002 - 国网全自动模式（PDF 第 1-7 页）需求规格

## 范围

全自动模式仅执行 PDF 第 1-7 页定义的三个国家电网栏目，并按国网站点配置的抓取天数处理公告：

1. 1.1 单一来源采购事前公示。
2. 1.2 年度采购计划预安排。
3. 2.1 资格预审公告。
4. 2.2 招标公告及投标邀请书。

南方电网不执行本工作流。

## 产品入口约束

1. 当前版本仅允许在“全自动模式”页面点击“执行”启动抓取，不提供顶部手动抓取入口或定时抓取功能。
2. 左侧菜单不展示定时抓取；已保存的历史定时配置不再执行。
3. 站点配置不提供关键词和地区筛选项；当前国网自动流程不依赖这些字段。
4. 站点配置先展示站点列表。用户点击已有站点时打开编辑信息，点击“添加站点”时才显示新建表单。国网站点不展示或编辑通用入口 URL，而是展示与保存 PDF 第 1-7 页三个自动步骤对应的固定页面路径；抓取天数和各步骤启用状态仍可配置。

## 功能需求

1. 左侧菜单提供“全自动模式”按钮；点击后仅切换到进度视图。页面最上方提供“执行”“打开保存目录”“删除历史”操作，其中仅“执行”启动三个栏目。
2. 进度视图使用上述三个 PDF 标题作为步骤，展示当前步骤、完成进度、结果状态和说明。
3. 每个栏目使用国网站点配置的抓取天数，未配置时默认 31 天；无更新时显示“无更新”，不创建新项目目录。手动重新执行时，若该窗口内已有公告的目录或 Word 文件被删除，必须恢复缺失归档。
4. 新增公告创建“日期 + 公告标题”目录，标题需适用于 Windows 文件系统，不插入额外分隔符。
5. 每个公告目录必须生成以公告页面标题命名的 `.docx` 文件，内容必须来自该公告详情页的正文和页面字段；不生成 `notice.html` 或详情 HTML 文件。
6. 单一来源采购事前公示与资格预审公告下载公开附件，附件直接存放在公告目录内，使用国网页面给出的附件文件名；年度采购计划预安排不主动下载附件。
7. 处理状态必须可在公告详情中查看。详情不可获取时，Word 文档保留可用的列表摘要，公告状态标记为待归档并说明原因。
8. “打开保存目录”直接打开用户配置的归档根目录；“删除历史”清除公告、任务、水位和已知归档目录后，只重置进度与页面数据，不自动执行抓取。用户需再次点击“执行”从头启动国网全自动流程。
9. 2.2 招标公告及投标邀请书须在公告目录内生成 `招标及结果.xlsx`，不得因详情或附件获取失败而省略；首个工作表的第一行按列依次为采购项目编号、采购项目名称、采购类型、招标文件获取截止时间、开标（截标）时间、招标人，第二行在对应列写入同一项目的值。详情可用时下载公告文件，并从附件需求一览表或货物清单中汇总分标名称、分标编号、包号、估算金额和数量。附件为 ZIP 时解压保留在公告目录；详情或附件不可用、未能自动识别的表格内容必须标记待复核。变更公告在工作簿中标记为变更待复核。
10. 自动步骤进入无更新、跳过、失败或成功终态时，所有尚未执行的子步骤必须完成状态收口，不得显示“等待执行”。无新增公告的子步骤显示“无新增公告，无需执行”。2.2 在抓取时间窗内已归档公告缺少 `招标及结果.xlsx` 时，必须视为缺失归档并在重新执行后补建。
11. 2.2 的国网页面链接、详情请求和“下载公告文件”公开下载接口均须优先使用公告 `noticeId`，不能误用列表 `detailId`。下载参数为公告 `noticeId` 和空值 `noticeDetId`，不得把列表详情 ID 填入 `noticeDetId`。详情接口暂时不可用时，仍须用公告 `noticeId` 下载公告文件。下载时使用响应头中的真实文件名；若响应内容为 ZIP，则保留原 ZIP，并自动解压到与 ZIP 同名的子目录，供标包需求整理读取。未标记 UTF-8 的 ZIP 内中文文件名按 GBK 解码，避免乱码。

## 验收场景

- 点击全自动模式后显示当前进度；点击“执行”后，三个步骤按顺序显示运行和完成状态。
- 本地模拟详情页成功时，归档目录内存在 `公告标题.docx` 和可公开下载的附件，不存在 HTML 快照文件；Word 正文与详情页字段一一对应。
- 无更新时，步骤显示无更新，归档根目录不创建新公告文件夹。
- 删除配置抓取范围内公告的归档目录或 `.docx` 后重新执行，步骤显示已恢复归档，缺失文件重新生成。
- 详情页不可用时，仍有 `公告标题.docx`，但公告处理状态为待归档并记录失败原因。
