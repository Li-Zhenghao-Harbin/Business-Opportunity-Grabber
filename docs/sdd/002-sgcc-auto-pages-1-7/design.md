# 002 - 国网全自动模式（PDF 第 1-7 页）设计规格

## 工作流

`RunSGCCAutoPages1To7` 选择 PDF 第 1-7 页三个栏目及 2.2 招标公告及投标邀请书，并为每个栏目调用既有国网分页、增量和归档流程。方法通过 Wails 事件 `automation:progress` 发布栏目级进度，以及抓取数据、创建文件夹、创建 Word 文档、下载附件、生成招标及结果 Excel 和更新状态六个子步骤的进度；前端按栏目和子步骤分别展示百分比。

2.2 归档完成附件下载后，创建 `招标及结果.xlsx`。首个工作表采用横向项目记录：第一行为六个项目字段列名，第二行为同一项目的对应值；其中招标文件获取截止时间与开标（截标）时间分别来自国网详情 `BIDBOOK_BUY_END_TIME` 与 `OPENBID_TIME`。标包需求单独建表，仅保存分标名称、分标编号、包号、估算金额、数量，不处理中标候选人。附件 ZIP 解压到公告目录，并读取其中的 `.xlsx` 工作簿，按“需求一览表”或“货物清单”相关列名识别并汇总同一分标、分标编号、包号的金额与数量；空分标名称优先用同一行项目名称回填。不能识别或旧版 `.xls` 文件不做猜测性转换，而是写入待复核说明；标题含“变更公告”的记录用红色状态标记。

国网 2.2 的页面路由、详情请求和公告文件下载统一优先使用公告 `noticeId`，列表 `detailId` 只作为缺失公告 ID 时的兼容回退。公告文件下载使用国网 `index/downLoadBid` 公开接口，与页面“下载公告文件”按钮保持一致：传 `noticeId` 并保留空值 `noticeDetId`，绝不将列表详情 ID 填入其中。若详情接口暂时不可用，归档层仍直接使用公告 `noticeId` 下载公告文件。归档层读取 `Content-Disposition` 中的实际文件名，并用 ZIP 文件签名而非扩展名判定是否解压；ZIP 原件保留在公告目录，解压内容写入以 ZIP 同名的子目录。对于未标记 UTF-8 的 ZIP 条目，归档层按 GBK 解码中文文件名，并拒绝不安全的压缩包路径。

整理标包需求会递归展开最多四层 ZIP；内层 ZIP 在其同名目录下解压。解析器识别“分标名称、分标编号、包号”列，也支持国网需求表常见的“分包编号”和“含税最高限价（万元）”列：从 `项目编号-分标编号-保留段-包号` 提取分标编号和包号，工作表标题中包含的“标段”作为缺省分标名称。最终按分标名称、分标编号、包号聚合金额和数量。若已下载 ZIP 的历史工作簿只有标包需求表头，归档恢复流程会重新生成工作簿。

2.2 结束后，汇总层递归扫描归档根目录内的 `招标及结果.xlsx`，读取固定的第一、第二工作表。每个源工作簿先在内存中按行横向拼接：第一工作表 A-F 的项目字段保留在左侧，第二工作表的五个标包字段复制至 G-K；每条标包记录重复带入对应项目的 A-F 字段，并仅对标包列执行向下填充。源工作簿保持不变。生成的 `招标投标统计数据.xlsx` 位于归档根目录，仅包含一个“招标投标统计数据”工作表，各源工作簿的临时拼接结果按扫描顺序连续写入；扫描条件只匹配源文件名，因此不会将统计文件本身再次纳入。

桌面窗口使用 Wails 的最大化启动状态。启动阶段只初始化当前用户配置目录中的 `opportunity-data.json`，前端仅加载站点、历史和归档配置；抓取接口只由“执行”按钮调用。默认站点和新增站点的抓取范围均为 3 天。Windows 下配置文件位于 `%APPDATA%\\商机提取器\\opportunity-data.json`，默认归档目录位于当前用户的“文档\\商机提取器归档”；两者均不随 EXE 发布。

国网站点配置的栏目保存 PDF 指定页面路径和菜单 ID，且只允许设置三个步骤的启用状态与统一抓取天数。通用入口 URL、抓取模式、间隔和重试次数不参与国网自动流程，因此不在国网站点配置页展示；非国网站点继续保留这些字段，为后续南网独立流程预留配置边界。

## Word 文档

归档层使用标准 Office Open XML 包生成最小有效 `.docx`，不依赖本机 Word 或 LibreOffice。文件名为清洗后的公告页面标题；国网栏目通过各自公开详情接口获得字段和正文，再写入 Word。单一来源和资格预审的公开附件直接保存到公告目录，保留页面给出的附件名。归档目录只保留 Word 文档和实际下载的附件，不生成 `notice.html` 或详情页 HTML 副本。

## 清除历史

`ClearHistory` 清除本地机会记录、任务记录及各站点栏目水位，并删除公告归档根目录下的全部一级文件和文件夹，保留根目录本身。删除前拒绝将磁盘根目录作为归档目录。前端在清理完成后重置全自动模式进度、显示结果并弹窗提示，但不启动抓取；用户点击“执行”后，才按首次抓取的规则处理当前时间窗内的公告。

## 目录打开

`OpenArchiveDirectory` 创建已配置的归档根目录后，使用系统文件管理器打开。该能力仅打开本地用户已配置目录，不上传或共享任何文件。

## 扩展边界

自动步骤使用栏目 ID 选择，不将国网菜单 ID 或 PDF 标题写入通用归档层。未来南网可增加独立自动工作流和步骤配置，复用进度事件、DOCX 归档和目录打开接口。
