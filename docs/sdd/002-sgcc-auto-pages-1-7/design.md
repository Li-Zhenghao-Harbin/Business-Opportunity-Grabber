# 002 - 国网全自动模式（PDF 第 1-7 页）设计规格

## 工作流

`RunSGCCAutoPages1To7` 仅选择三个固定栏目，并为每个栏目调用既有国网分页、增量和归档流程。方法通过 Wails 事件 `automation:progress` 发布栏目级进度，以及抓取数据、创建文件夹、创建 Word 文档、下载附件和更新状态五个子步骤的进度；前端按栏目和子步骤分别展示百分比。

## Word 文档

归档层使用标准 Office Open XML 包生成最小有效 `.docx`，不依赖本机 Word 或 LibreOffice。文件名为清洗后的公告标题；正文优先使用详情页提取文本，详情不可用时使用公告列表摘要并在状态中体现待归档。归档目录只保留 Word 文档和实际下载的附件，不生成 `notice.html` 或详情页 HTML 副本。

## 清除历史

`ClearHistory` 清除本地机会记录、任务记录及各站点栏目水位，并删除这些历史记录对应的归档文件夹。前端在清理完成后立即启动国网全自动模式，按首次抓取的规则处理当前时间窗内的公告；该方法只删除已被系统记录的归档路径，避免影响保存根目录中的其他文件。

## 目录打开

`OpenArchiveDirectory` 创建已配置的归档根目录后，使用系统文件管理器打开。该能力仅打开本地用户已配置目录，不上传或共享任何文件。

## 扩展边界

自动步骤使用栏目 ID 选择，不将国网菜单 ID 或 PDF 标题写入通用归档层。未来南网可增加独立自动工作流和步骤配置，复用进度事件、DOCX 归档和目录打开接口。
