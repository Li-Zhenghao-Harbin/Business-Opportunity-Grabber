# 001 - 国网 P0 需求规格

## 目标

将国家电网 ECP 从单一公告列表采集扩展为可配置栏目、每日增量、可追溯归档的采集流程。南方电网不在本规格的业务范围内，但必须能复用站点适配、栏目、水位和归档契约。

## 功能需求

1. 国网内置七个独立栏目，可单独启停并在任务日志中独立统计。
2. 每个栏目保存抓取水位：最后成功时间、最新公告时间、最新公告标识。
3. 定时任务支持固定间隔和每天固定时间两种方式；每日模式按最近 24 小时增量抓取。
4. 国网列表接口必须分页读取，直到到达时间边界、已越过水位或无下一页。
5. 新增或更新的公告必须进入归档流程：保存离线 HTML 摘要、抓取详情页面、尝试下载可公开访问的附件。
6. 用户可配置归档根目录，并可通过系统目录选择器选择目录。
7. 公告必须暴露处理状态和归档位置。详情页面或附件不可获取时，必须记录明确失败原因，不得标记为已归档。
8. 归档路径、附件元数据和抓取水位均持久化到本地数据文件。

## 非目标

- 不实现南网的详情、附件和栏目规则。
- 不解析 Excel/PDF 附件，也不生成项目、标包和中标数据。
- 不实现需要登录、验证码或绕过访问控制的下载。

## 验收场景

### 栏目和水位

- 新安装的应用包含七个启用的国网栏目；南网站点没有自动套用国网栏目。
- 停用某个栏目后，手动和定时抓取均不执行该栏目。
- 国网栏目成功执行后更新自己的水位；失败不会推进水位。

### 增量和分页

- 多页列表中，指定日期范围的公告均被收集。
- 每日任务以最近 24 小时为默认窗口，手动补抓不会覆盖正常水位。
- 无新增时任务显示“无更新”，不创建归档目录。

### 归档

- 用户设置的根目录下，新增公告创建以“日期 + 标题”为基础、可用于 Windows 的目录名。
- 每个归档目录包含 `notice.html` 离线摘要；正文获取成功时额外保留详情快照；附件下载成功后记录其文件信息。
- 详情或附件下载失败时，公告显示“待归档”或“归档失败”及原因，并能从任务日志回查。
