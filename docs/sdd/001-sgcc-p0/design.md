# 001 - 国网 P0 设计规格

## 领域模型

- `SiteConfig` 拥有可选的 `Categories` 和每个栏目独立的 `Watermarks`。
- `NoticeCategory` 是站点栏目配置，不包含特定站点的抓取实现。
- `SiteAdapter` 是站点适配边界。当前实现 `SGCCAdapter`；其他站点可保留列表采集或新增自己的适配器。
- `ArchiveConfig` 保存用户选择的根目录。
- `Opportunity` 保存栏目、公告标识、处理状态、归档目录、详情抓取时间、附件元数据和错误原因。

## 执行流程

1. 解析站点的启用栏目。
2. 由适配器分页读取列表，并按手动范围或栏目水位过滤。
3. 对新发现或更新公告执行归档：创建目录、写入离线摘要、读取详情页、提取公开附件并下载。
4. 将公告、附件元数据和处理状态写入数据文件。
5. 仅在栏目流程成功完成后推进该栏目水位。

## 失败策略

- 列表请求失败：栏目任务失败，水位不推进。
- 详情或单个附件失败：列表采集仍成功，公告标记为待归档或归档失败，任务中记录失败数量。
- 公开详情页面只有 SPA 外壳或没有正文：保留离线摘要，状态为待归档，并保存可读原因。

## 扩展点

新增南网流程时，只需新增 `CSGAdapter` 与其 `NoticeCategory` 模板；共用水位、归档、附件、状态和任务模型，不复制国网业务规则。
